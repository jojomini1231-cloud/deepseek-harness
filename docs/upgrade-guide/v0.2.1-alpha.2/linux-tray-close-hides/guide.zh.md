# Linux Desktop 关闭窗口进入托盘

English | [中文](guide.md)

## 变更

Linux 上的 Desktop 之前在关闭主窗口时会经常规任务确认退出应用，因为没有托盘可以找回隐藏的窗口。现在应用与 Windows 一致，在整个运行期间常驻托盘图标：关闭主窗口——窗口管理器的关闭或自绘标题栏的关闭按钮——会在一次性确认后隐藏窗口，Host 与任务继续运行，托盘菜单中的"打开"项、面板支持时的托盘单击，或再次启动应用都能找回窗口。托盘图标需要桌面环境支持 StatusNotifierItem；GNOME 仅在启用其 AppIndicator 扩展时显示，libappindicator 面板不派发单击事件，此时请使用菜单。托盘菜单中的"退出 DeepSeek Harness"项是 Linux 上的显式退出入口，走与之前关窗相同的任务中断确认。托盘图标完全无法创建时，Linux 保持原有行为：关窗经常规确认退出。Windows 与 macOS 行为不变。

## 迁移

1. 在 GNOME 上启用 AppIndicator 扩展（新版 Ubuntu 已默认安装并启用）让图标显示；其他桌面环境无需操作。
2. 如果之前依赖关闭窗口来退出应用，请改用托盘菜单中的"退出 DeepSeek Harness"；停止 Host 任务前会弹出同样的中断确认。
3. 确认升级生效：关闭主窗口后，经一次性确认窗口会隐藏，托盘图标保留，从托盘重新打开时恢复同一文档。
4. 如果环境中不显示托盘图标，再次启动应用即可——第二次启动会聚焦隐藏的窗口——托盘创建失败时关窗恢复退出行为，应用不会因此失去联系。
